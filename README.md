# Travel Expense Bot 🚗 🚌

בוט טלגרם חכם לניהול ומעקב אחר החזרי נסיעות חודשיים ברכב ובתחבורה ציבורית בישראל.

## 🚀 תכונות עיקריות
- 🚗 **חישוב נסיעות ברכב:** חישוב מרחק אוטומטי מכתובת המוצא (הכ"ג 5, הרצליה) הלוך-חזור לפי תעריף לק"מ (1.40 ₪).
- 🚌 **פענוח תחבורה ציבורית מבוסס AI:** קריאה ופענוח של צילומי מסך והיסטוריית חיובים (Moovit, רב-קו אונליין, פנגו וכו') בעזרת Gemini Vision.
- 📊 **דוחות Excel מובנים:** הפקת קובץ אקסל מעוצב בדיוק לפי הטמפלייט החודשי עם נוסחאות וסיכומים.
- ⏰ **תזמון אוטומטי:**
  - 🔔 29 לחודש: תזכורת להזנת נסיעות החודש.
  - 🔔 1 לחודש: תזכורת לסגירת החודש שחלף.
  - 📄 3 לחודש: הפקה ושליחה אוטומטית של קובץ האקסל המסכם לטלגרם.

## 🛠️ פריסה ב-Render (חינמי 24/7)
1. צור **New Web Service** ב-Render וחבר את ה-Repository הזה.
2. **Build Command:** `pip install -r requirements.txt`
3. **Start Command:** `python bot.py`
4. תחת **Environment Variables**, הגדר:
   - `TELEGRAM_BOT_TOKEN`
   - `GEMINI_API_KEY`
   - `ORIGIN_ADDRESS` = `הכ"ג 5, הרצליה`
   - `RATE_PER_KM` = `1.40`
5. הגדר שירות פינג חינמי (כמו **UptimeRobot** או **cron-job.org**) לכתובת ה-URL ש-Render נותן לך (למשל `https://travel-expense-bot.onrender.com/`) כל 10 דקות לשמירה על השרת ערני 24/7.
